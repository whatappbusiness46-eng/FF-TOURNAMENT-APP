ZyroX Arena — publish-ready project

1. Deploy backend/ to a persistent Node hosting service.
2. Set EXPO_PUBLIC_API_URL to the backend URL in the EAS environment before building.
3. Preview profile creates an installable Android APK.
4. Production profile creates an Android AAB for Google Play.
5. bKash/Nagad automatic payments require approved merchant/API credentials; without them, the included flow is manual/admin verification.
6. The included JSON backend is an MVP foundation; production real-money traffic should use a persistent database and hardened authentication.
